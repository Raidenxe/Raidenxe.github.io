Linux 文本三剑客之 sed：流编辑器从入门到精通

一、sed 引言与历史

1.1 sed 是什么？

sed（stream editor，流编辑器）是一个使用简单紧凑的编程语言来解析和转换文本的 Unix 实用程序。它最显著的特点是对输入只做一次遍历即可完成编辑，因此效率极高。与交互式编辑器不同，sed 尤其擅长在管道中过滤和转换文本——这也是它与其他编辑器最本质的区别。

1.2 sed 在文本三剑客中的定位

工具 核心能力 典型场景 复杂度
grep 按模式搜索并输出匹配行 日志过滤、关键字查找 ⭐ 入门级
sed 对文本流进行替换/删除/插入 批量替换、行编辑 ⭐⭐ 中级
awk 按字段处理结构化文本，支持编程逻辑 报表生成、数据提取 ⭐⭐⭐ 高级

grep 更适合单纯的查找；sed 更适合编辑匹配到的文本；awk 更适合对结构化文本做字段级分析。

1.3 历史由来

sed 由贝尔实验室的李·E·麦克马洪（Lee E. McMahon） 于 1973 年至 1974 年开发，现在几乎所有操作系统都可以使用。sed 基于交互式编辑器 ed（1971 年）和更早的 qed（1965-66 年）的脚本功能，是最早支持正则表达式的工具之一，至今仍广泛用于文本处理，特别是替换命令。

二、sed 工作原理

sed 的工作方式是逐行处理：

  1. 从文件或管道中读取一行
  2. 将当前行存入临时缓冲区——模式空间（Pattern Space）
  3. 用 sed 命令对模式空间中的内容进行处理
  4. 处理完成后，将缓冲区的内容输出到屏幕
  5. 读取下一行，重复上述过程，直到文件末尾

逐行处理带来的优势：

  • 性能极高：sed 在读取大文件时不会出现卡顿
  • 内存友好：与 vi 等编辑器一次性加载整个文件不同，sed 每次只处理一行
  • 管道友好：可以从标准输入读取，与管道完美配合

如果使用 vi 打开几十兆上百兆的文件，会明显卡顿——因为 vi 是一次性将整个文件加载到内存。而 sed 一行一行地处理，打开速度和执行速度都非常快。

三、sed 的作用

sed 可依照脚本的指令来处理、编辑文本文件，主要能力包括：

  • ✅ 增删改查：新增行、删除行、替换文本、查找匹配
  • ✅ 取行：按行号或正则表达式提取指定行
  • ✅ 替换：支持正则替换，是 sed 最常用的功能
  • ✅ 自动化编辑：简化对文件的反复操作，编写转换程序

典型应用场景：

  • 📝 批量替换：在多个文件中统一替换配置项
  • 🔄 格式转换：将日期格式从 MM/DD/YYYY 转为 YYYY-MM-DD
  • ✂️ 文本提取：从日志中提取特定时间段的内容
  • 📄 模板处理：用脚本自动生成配置文件或报告

五、sed 常用选项详解

选项 长选项 说明
-n --quiet, --silent 静默模式，不自动输出模式空间的内容。只有显式使用 p 命令时才输出
-e SCRIPT --expression=SCRIPT 添加一个 sed 命令到待执行的命令序列中。可多次使用
-f FILE --file=FILE 从 FILE 中读取 sed 脚本
-i --in-place 直接修改文件（原地编辑），而非输出到屏幕。可加后缀名创建备份，如 -i.bak

最重要的选项：-n（控制输出）和 -i（原地编辑）。-n 几乎总是和 p 命令配合使用；-i 是批量修改文件的利器，但用之前建议先不加 -i 预览效果。

六、sed 地址与动作

6.1 地址表示法

sed 命令可以指定地址，以控制对哪些行执行操作。地址可以是：

地址类型 格式 示例
单行号 N sed '5p' —— 第 5 行
行号范围 N,M sed '1,5p' —— 第 1 到 5 行
正则表达式 /pattern/ sed '/error/p' —— 匹配 “error” 的行
最后一行 $ sed '$p' —— 最后一行
取反 ! sed '/error/!p' —— 不匹配 “error” 的行

6.2 基本动作

动作 说明 示例
p 打印（输出）模式空间的内容 sed -n '1,5p' file
d 删除模式空间的内容，立即开始下一轮循环 sed '1d' file
s 替换（最常用），格式：s/正则/替换/修饰符 sed 's/old/new/g' file
a 在指定行后面追加文本 sed '3a\新内容' file
i 在指定行前面插入文本 sed '3i\新内容' file
c 替换指定行 sed '3c\新内容' file
y 逐字符替换（类似 tr 命令） sed 'y/abc/ABC/' file

替换修饰符：

修饰符 含义
g 全局替换（替换行内所有匹配，而非仅第一个）
数字 只替换第 N 个匹配，如 s/old/new/2
p 当发生替换时，打印该行（与 -n 配合）
w FILE 将替换成功的行写入 FILE

十、sed 速查备忘卡

十一、小结

sed 是 Linux 文本处理三剑客中承上启下的关键角色——比 grep 更强大，比 awk 更轻量。回顾本文要点：

  1. 逐行处理是 sed 的核心设计——模式空间 + 一次遍历，高效且内存友好；
  2. 地址 + 动作是 sed 的基本语法模式——地址决定”对哪些行”，动作决定”做什么”；
  3. s 命令是 sed 的灵魂——配合正则表达式和逆参照，可以实现复杂的文本转换；
  4. BRE vs ERE——默认使用 BRE（{}、() 需转义），使用 -E 切换到 ERE 更简洁；
  5. **脚本文件让 sed 从”单行工具”升级为”编程语言”**——多命令组合，实现自动化报告生成；
  6. -i 是双刃剑——方便但危险，建议先预览再原地修改，或使用 -i.bak 保留备份。
