Docker 常用命令速查笔记

一、镜像管理（Image）

命令 用途 示例
docker images 列出本机所有镜像 docker images
docker pull <镜像名>:<标签> 从仓库拉取镜像 docker pull nginx:1.25
docker rmi <镜像ID或名称> 删除镜像（可加 -f 强制） docker rmi nginx:1.25
docker tag <源镜像> <目标镜像:标签> 给镜像打标签 docker tag myapp:v1 myapp:latest
docker inspect <镜像名> 查看镜像详细信息（JSON格式） docker inspect nginx
docker save -o <文件名>.tar <镜像名> 导出镜像为 tar 文件 docker save -o nginx.tar nginx:1.25
docker load -i <文件名>.tar 从 tar 文件导入镜像 docker load -i nginx.tar

二、容器生命周期（Container Lifecycle）

创建与启动

命令 用途 示例
docker run <镜像名> 创建并启动容器（最常用） docker run -d --name web nginx
docker run -p 宿主机端口:容器端口 端口映射 docker run -p 8080:80 nginx
docker run -P 随机端口映射（宿主机随机端口→容器暴露端口） docker run -P nginx
docker run --name <容器名> 指定容器名称 docker run --name mynginx nginx
docker run -d 后台运行（detach） docker run -d nginx
docker run --restart=always 设置容器自动重启策略 docker run --restart=always nginx
docker run -e KEY=VALUE 设置环境变量（常用于数据库密码等） docker run -e MYSQL_ROOT_PASSWORD=123456 mysql

查看与操作

命令 用途 示例
docker ps 列出正在运行的容器 docker ps
docker ps -a 列出所有容器（含已停止） docker ps -a
docker stop <容器名或ID> 停止一个运行中的容器 docker stop web
docker start <容器名或ID> 启动一个已停止的容器 docker start web
docker restart <容器名或ID> 重启容器 docker restart web
docker rm <容器名或ID> 删除容器（已停止） docker rm web
docker rm -f <容器名或ID> 强制删除运行中的容器 docker rm -f web
docker container prune 删除所有已停止的容器（推荐） docker container prune
docker rm $(docker ps -a -q) 删除所有容器（含运行中的，慎用） ——

三、容器管理（查看与调试）

命令 用途 示例
docker logs <容器名> 查看容器日志 docker logs web
docker logs -f <容器名> 实时跟踪日志（类似 tail -f） docker logs -f web
docker exec -it <容器名> <命令> 在运行中的容器内执行命令（最常用） docker exec -it web bash
docker attach <容器名> 连接到容器的交互式 shell（不推荐） ——
docker cp <宿主机文件> <容器名>:<容器路径> 从宿主机拷贝文件到容器 docker cp ./a.txt web:/app/
docker cp <容器名>:<容器路径> <宿主机路径> 从容器拷贝文件到宿主机 docker cp web:/app/a.txt ./
docker top <容器名> 查看容器内运行的进程 docker top web
docker stats 实时查看容器资源使用（CPU/内存/网络） docker stats
docker inspect <容器名> 查看容器的详细元数据（包括 IP、端口、挂载卷等） docker inspect web

四、与容器和虚拟机的对比（概念补充）

对比项 容器（Docker） 虚拟机（VM）
启动速度 秒级 分钟级
资源占用 轻量，共享宿主机内核 重量，每个 VM 有自己的完整 OS
隔离级别 进程级隔离 硬件级隔离
镜像大小 MB 级别 GB 级别
迁移性 高（跨云、跨环境） 一般（需要兼容 hypervisor）

五、实用组合套路（快速上手）

场景 命令组合
部署一个 Nginx 并映射端口 docker run -d --name web -p 80:80 nginx
进入容器调试 docker exec -it web bash 或 sh
查看容器 IP docker inspect web | grep IPAddress
清理所有已停止容器 docker container prune
一键清理所有未使用资源 docker system prune（含镜像、网络、构建缓存）

简单实战案例一：使用 Docker 快速部署 Spug

什么是 Spug

Spug 是一个开源的轻量级运维平台，包含主机管理、批量执行、在线终端、文件管理、任务计划等功能。它采用前后端分离架构，后端基于 Python Django + DRF，前端基于 React + Ant Design。使用 Docker Compose 可以快速部署 Spug，无需手动配置 Python 环境和数据库。

环境准备

部署前请确保已完成以下准备：

  • Docker 和 Docker Compose 已安装（可使用本文前面的脚本安装）
  • 服务器至少有 2GB 内存（推荐 4GB）
  • 开放 80 端口用于访问 Web 界面
