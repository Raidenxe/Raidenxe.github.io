Linux常用命令总结

命令行界面（CLI）是与计算机交流的一种非常高效的方式，正如人类社会用文字互通信息一样。

“图形用户界面让简单的任务更容易完成，而命令行界面使完成复杂的任务成为可能。”

下面整理了一些常用的查看 Linux 基本信息的命令，并附上扩展参数以供深入使用。

一、查看系统信息

查看主机名

  • hostname
  • 扩展：hostname -i（显示本机 IP）、hostname -f（完整域名）

查看 CPU 信息

  • lscpu
  • 扩展：lscpu -e（可扩展格式）、lscpu -p（可解析的 CPU 列表）

查看发行版本

  • cat /etc/issue
  • lsb_release -a
  • cat /etc/redhat-release（适用于 RPM 系发行版）
  • cat /etc/os-release（通用系统信息文件）

查看系统信息

  • uname -a
  • 扩展：uname -s（内核名称）、uname -r（内核版本）、uname -m（硬件架构）

查看 Linux 内核版本

  • uname -r
  • cat /proc/version

查看操作系统的位数

  • uname -m
  • getconf LONG_BIT（直接返回 32 或 64）

查看设备文件

  • ls /dev
  • ls /dev/sd*（仅列出磁盘设备）
  • lsblk（以树形列出块设备）

列出所有 PCI 设备

  • lspci -tv
  • 扩展：lspci -nn（显示厂商和设备 ID）、lspci -k（显示内核驱动）

列出所有 USB 设备

  • lsusb -tv
  • 扩展：lsusb -v（详细输出）、lsusb -d 厂商:设备（过滤特定设备）

列出已加载的内核模块

  • lsmod
  • 扩展：lsmod | grep <模块名>（过滤）、modinfo <模块名>（查看模块详情）

查看环境变量

  • env
  • 扩展：env | sort（排序显示）、echo $变量名（查看单个变量）

二、查看资源信息

查看内存使用情况

  • free -m（以 MB 为单位）
  • 扩展：free -h（人类可读格式）、free -s 2（每 2 秒持续刷新）

查看所有进程

  • ps -elf
  • 扩展：ps aux（BSD 风格，显示所有用户进程）、ps -eo pid,comm,%cpu --sort=-%cpu（自定义输出并按 CPU 排序）

查看磁盘使用情况

  • df -h
  • 扩展：df -T（显示文件系统类型）、df -i（显示 inode 使用情况）

查看磁盘 I/O 使用情况

  • iostat -x 1（每秒刷新一次扩展统计）
  • 扩展：iostat -m 1（以 MB 为单位）、iostat -p sda 1（仅监控指定磁盘）

查看所有交换分区

  • swapon -s（或 swapon --show）

查看系统运行时间、用户数、负载

  • uptime
  • 扩展：uptime -p（仅显示运行时间）、uptime -s（显示启动时间）

查看系统负载

  • cat /proc/loadavg
  • 补充：top -bn1 | head -n 5（获取即时负载摘要）

查看 CPU 使用率等信息（类似 Windows 任务管理器）

  • top
  • htop（top 增强版，界面更直观）
  • glances（功能更丰富，可监控多维度资源）
  • 扩展：top -bn1（非交互式输出一次）、htop -d 10（刷新间隔 0.1 秒）、glances -w（启动 Web 服务监控）

三、查看用户信息

查看活动用户

  • w
  • 扩展：w -h（不显示头信息）、w -s（简短格式）

查看用户登录日志

  • last
  • 扩展：last -n 5（最近 5 次登录）、last -a（主机名显示在最后一列）

查看历史命令

  • history
  • cat ~/.bash_history（记录上一次登录以前所执行过的命令）
  • 扩展：history -c（清除当前会话历史）、history | grep <关键词>（搜索历史）

查看当前用户信息

  • id
  • 扩展：id <用户名>（查看指定用户）、id -g（仅显示主组 ID）

查看系统所有用户

  • cut -d: -f1 /etc/passwd

查看系统所有组

  • cut -d: -f1 /etc/group

查看当前用户的计划任务

  • crontab -l
  • 扩展：crontab -e（编辑计划任务）、crontab -u <用户名> -l（查看其他用户的任务，需权限）

四、查看网络信息

查看本机 IP 地址

  • ip a（或 ip addr）
  • 扩展：ip -brief addr（简洁输出）、ip addr show dev eth0（查看特定接口）

显示或配置网络设备（查看所有网络接口属性）

  • ifconfig
  • 扩展：ifconfig eth0（查看特定接口）、ifconfig -a（显示所有接口，包括停用的）

查看路由表

  • ip route
  • route -n
  • 扩展：ip route show table all（显示所有路由表）、route -n -6（查看 IPv6 路由）

查看防火墙设置

  • iptables -L（可能需要 root 权限）
  • 扩展：iptables -L -v -n（详细规则并显示端口号）、iptables -t nat -L（查看 NAT 规则）

查看所有监听端口

  • netstat -lntp
  • 扩展：netstat -tulnp（同时显示 TCP 和 UDP 监听端口）、ss -lntp（更快的替代命令）

查看所有已建立的连接

  • netstat -antp
  • 扩展：netstat -ant | grep ESTABLISHED（仅过滤已建立连接）、ss -antp（现代替代方案）

查看网络统计信息

  • netstat -s
  • 扩展：netstat -i（查看网络接口统计）

网络诊断工具（测试连通性）

  • ping
  • 扩展：ping -c 4 <主机>（发送 4 个包后停止）、ping -i 0.2 <主机>（缩短发送间隔）

路由跟踪

  • traceroute
  • 扩展：traceroute -n <主机>（不进行 DNS 解析，加快速度）、mtr <主机>（动态路由追踪与实时统计）

五、查看硬件与设备信息

查看详细硬件信息

  • lshw（需 root，信息全面）
  • dmidecode -t system（显示系统制造商、序列号等，需 root）
  • hwinfo --short（硬件摘要，部分发行版需安装）

查看块设备与 UUID

  • lsblk -f（显示块设备、挂载点、文件系统类型和 UUID）
  • blkid（列出所有块设备的 UUID 和文件系统）

查看磁盘具体型号和序列号

  • hdparm -I /dev/sda（需 root）
  • smartctl -a /dev/sda（查看 SMART 状态，需 root）

六、查看系统日志与启动信息

查看内核环形缓冲区消息（启动信息）

  • dmesg
  • 扩展：dmesg -T（可读时间戳）、dmesg | grep -i error（过滤错误）

查看系统日志（systemd 系统）

  • journalctl
  • 扩展：journalctl -xe（最新日志并解释）、journalctl -u sshd（查看特定服务日志）、journalctl --since "2026-06-22"（按时间筛选）

查看登录失败记录

  • lastb（需要 root 权限，用于检查暴力破解尝试）

七、查看进程与服务管理

查看系统服务状态

  • systemctl list-units --type=service --state=running（列出所有运行中的服务）
  • systemctl status <服务名>（查看某个服务的详细状态）

查看所有已安装的服务单元文件

  • systemctl list-unit-files --type=service

列出由打开的文件（进程与文件关联）

  • lsof
  • 扩展：lsof -i :80（查看占用 80 端口的进程）、lsof -u root（查看 root 用户打开的文件）

实时 I/O 监控

  • iotop（需 root 或 sudo）

系统活动报告（需安装 sysstat 包）

  • sar -u 1 3（每秒输出一次 CPU 使用率，共 3 次）
  • sar -n DEV 1（查看网络接口速率）

多处理器使用率

  • mpstat -P ALL 1（每核 CPU 使用率）

八、查看网络 DNS 与接口

查看和排错 DNS

  • dig baidu.com（信息更丰富）
  • nslookup baidu.com（传统 DNS 查询）
  • host baidu.com（简洁的 DNS 查询）

查看 ARP 缓存表

  • ip neighbor（或 arp -n）

查看网卡速率、双工模式等

  • ethtool eth0（需 root）

监听网络流量（抓包）

  • tcpdump -i eth0 -c 100（抓取 100 个包后停止）
  • 扩展：tcpdump -n host 192.168.1.1（过滤指定主机）

九、查看文件与目录使用情况

查看文件或目录大小

  • du -sh <目录>（常用 du -sh * 查看当前目录下各文件/目录大小）
  • 扩展：du -h --max-depth=1（一层深度显示）

查看当前挂载及文件系统类型

  • mount | column -t（排版清晰）
  • findmnt（树形结构显示挂载关系）

十、查看系统时间和时区

显示系统日期时间与时区

  • date
  • timedatectl（查看并管理系统时间、时区、NTP 同步状态）
  • 扩展：timedatectl list-timezones（列出所有时区）

十一、查看内核参数与模块信息

查看当前内核参数

  • sysctl -a（列出所有内核参数及其值）
  • 扩展：sysctl net.ipv4.ip_forward（查看单个参数）

查看模块详细信息

  • modinfo <模块名>（如 modinfo e1000e）

十二、查看软件包与版本

列出已安装的软件包（根据包管理器不同）

  • rpm -qa（RPM 系，如 CentOS/RHEL）
  • dpkg -l（Debian/Ubuntu）
  • pip list（Python 包）
  • gem list（Ruby 包）

查看某个命令的版本或所在包

  • which <命令>（显示命令路径）
  • whereis <命令>（显示命令、源码、手册页位置）
  • rpm -qf /bin/ls（查询文件属于哪个 RPM 包）
  • dpkg -S /bin/ls（查询文件属于哪个 Debian 包）

十三、文件搜索命令

查找文件（实时遍历目录）

  • find <路径> -name "*.log"（按名称搜索，支持通配符）
  • 常用参数：
    • find / -type f -size +100M（查找大于 100MB 的文件）
    • find /var/log -mtime -7（查找最近 7 天修改过的文件）
    • find /home -user alice（查找属于某个用户的文件）
    • find /tmp -name "*.tmp" -exec rm {} \;（找到并删除文件）

快速搜索文件（基于数据库）

  • locate <文件名>（需先运行 updatedb 更新数据库）
  • 扩展：locate -i .conf（不区分大小写）、locate -c bash（只统计匹配数量）

查找可执行文件、源码及手册页

  • whereis <命令名>（示例：whereis python）
  • 扩展：whereis -b python（仅查找二进制文件）

查找命令的绝对路径

  • which <命令名>（示例：which java）

判断一个命令是内置还是外部命令

  • type <命令名>（示例：type cd）

在文件内容中搜索文本

  • grep -r "关键词" <目录>（递归搜索）
  • 常用参数：
    • grep -i "error" /var/log/messages（忽略大小写）
    • grep -rn "TODO" .（递归显示行号）

十四、软件包管理命令

RPM 系（RHEL/CentOS/Fedora 等）

  • 搜索软件包：yum search <关键词> 或 dnf search <关键词>
  • 列出可更新的软件包：yum check-update 或 dnf check-update
  • 安装软件包：yum install <包名>（加 -y 自动确认）
  • 卸载软件包：yum remove <包名> 或 dnf remove <包名>
  • 更新所有软件包：yum update 或 dnf update
  • 列出已安装的软件包：rpm -qa、yum list installed（或 dnf list --installed）
  • 查看软件包详细信息：yum info <包名> 或 rpm -qi <包名>
  • 查看文件属于哪个安装包：rpm -qf /bin/ls
  • 清理缓存：yum clean all 或 dnf clean all

Debian 系（Ubuntu/Debian 等）

  • 更新软件源索引：apt update
  • 搜索软件包：apt search <关键词> 或 apt-cache search <关键词>
  • 安装软件包：apt install <包名>（加 -y 自动确认）
  • 卸载软件包：apt remove <包名>（保留配置文件）、apt purge <包名>（彻底删除）
  • 更新所有已安装的软件包：apt upgrade、apt dist-upgrade（智能处理依赖关系）
  • 列出已安装的软件包：dpkg -l、apt list --installed
  • 查看软件包详细信息：apt show <包名>、dpkg -s <包名>
  • 查看文件属于哪个已安装的包：dpkg -S /bin/ls
  • 清理下载的缓存文件：apt clean、apt autoclean
  • 卸载不再需要的依赖包：apt autoremove

以上命令涵盖了系统管理中最常需要查看和获取信息的方方面面，建议根据实际需求组合使用，并注意部分命令需要 root 权限或额外安装相应软件包。
